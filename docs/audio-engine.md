# Audio engine

`AudioService` (`app/services/audio_service.py`) owns every audio workflow. Low-level primitives live in `app/utils/audio.py`:

- decode/encode (libsndfile, with FFmpeg as a fallback)
- metadata and waveform peaks
- K-weighted loudness (BS.1770-style gating)
- RBJ biquads
- resample, fade, trim, concat

Audio is processed as mono float32 and stored internally as 16-bit WAV.

## Non-destructive rule

No operation overwrites a file:

- **Import** copies the original (`audios.original_path`) and writes a WAV working copy (`audios.path`).
- **Processing and edits** create a *new* `audios` row with `parent_audios_id` pointing at the source.
- **TTS** saves the raw generation as `original_path` and the cleaned version as `path`.

## Enhancement pipeline

Steps run in a fixed order: `trim_silence → denoise → eq → compress → deess → normalize → limit → loudness`.

| Step | Implementation | Options |
|---|---|---|
| trim_silence | frame RMS threshold with padding | `threshold_db`, `pad_ms` |
| denoise | STFT spectral gating against the quietest 15% of frames | `strength` 0–1 |
| eq | high-pass, presence peak (3 kHz), low peak, high shelf | `highpass_hz`, `presence_db`, `low_db`, `high_db` |
| compress | RMS envelope, static curve | `threshold_db`, `ratio`, `makeup_db` |
| deess | high-band (6 kHz) dynamic reduction | `frequency`, `threshold_db`, `ratio` |
| normalize | peak normalize | `peak_db` |
| limit | 5 ms peak-hold gain, then hard ceiling | `ceiling_db` |
| loudness | gain to target LUFS, then limit | `target_lufs`, `ceiling_db` |

Presets live in `app/constants/audio.py` (`ENHANCE_PRESETS`): Raw, Voice Clean, Podcast, Narration, Lesson and Studio. `AudioService.resolve_steps(steps, preset)` merges a preset with explicit steps; passing `{"step": None}` disables that step.

- `process_array(y, sr, steps)` is a pure function.
- `process(audios_id, steps, preset)` writes a new processed audio.

## Editor operations

`apply_edit_ops(y, sr, ops)` replays an edit list. Times are in seconds.

| op | fields |
|---|---|
| `delete` / `cut` | start, end |
| `crop` / `trim` | start, end |
| `insert` / `paste` | at, clip (WAV path from `save_clip`) |
| `append` | clip, gap |
| `silence` | at, duration |
| `duplicate` | start, end |
| `move` | start, end, to |
| `gain` / `volume` | start, end, db |
| `fade_in` / `fade_out` | start, end |
| `normalize` | start, end, peak_db |
| `enhance` | start, end, steps or preset |

The Audio Editor page keeps `ops` and a cached state per step for instant undo and redo. The source is never touched.

- **Render** calls `render_edits(audios_id, ops)`, which creates a new audio.
- **Split** renders the edits, then calls `split(audios_id, at)`, which creates two audios.
- **Autosave** stores the op list in `projects.edit_state["editor"][audios_id]`.

## Export and labelling

`export(audios_id, dest, fmt, sample_rate)` writes WAV, FLAC, OGG or MP3 through libsndfile, and M4A through FFmpeg. Audio flagged `ai_generated` is written with a `comment` tag of "AI-generated by VoxLabs" (`AI_GENERATED_TAG`). Every file is written with `software=VoxLabs`.

## Analysis

`analyze(path)` returns:

- duration, sample rate and channels
- peak and RMS dB, loudness in LUFS
- silence ratio, clipping ratio, noise floor and SNR
- a 0–100 quality score and a list of human-readable issues

The Clone page uses it for sample quality checks.
